# 🌐 Responsive Personal Portfolio & Blog Website

## 📌 Project Overview

This project is a **responsive personal portfolio website** developed using core front-end technologies. It demonstrates concepts like HTML structure, CSS styling, Flexbox layouts, JavaScript (DOM), and responsive design using media queries.

The website includes multiple pages such as Home, About, Gallery, Projects, and Contact, providing a complete real-world web application experience.

---

## 🎯 Objectives

* Understand and implement **HTML5 semantic structure**
* Design layouts using **CSS3 and Flexbox**
* Create responsive UI using **Media Queries**
* Implement **JavaScript DOM manipulation**
* Build and validate **forms**
* Develop a structured multi-page website

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript (DOM)**
* **Flexbox**
* **Media Queries**

## ✨ Features Implemented

### 🏠 Home Page

* Introduction and welcome message
* Navigation bar
* Semantic layout (header, nav, section, footer)

### 📄 About Page

* Personal details
* Skills and interests
* Media object layout (image + text)

### 🖼️ Gallery Page

* Displays multiple images
* Flexbox layout
* Hover effects (zoom + shadow)

### 📦 Projects Section

* Card-based UI design
* Includes title, description, and buttons
* Hover animations

### 📩 Contact Form

* Input fields: Name, Email, Message
* HTML5 validation
* Styled form UI

### ⚡ JavaScript (DOM)

* Form submission handling
* Validation using JavaScript
* Alert message on successful submission

### 📱 Responsive Design

* Mobile-friendly layout
* Media queries for different screen sizes
* Adaptive navigation, gallery, and cards
